# SECTIONS — page-by-page build spec

Copy for every section lives in `docs/content/*.md` (cleaned scrape text). Full-page screenshots (desktop) go in `docs/screenshots/` (see ASSETS.md). This file maps **structure → components → behaviour**.
Class names (`tp-*`) are the reference site's; use them as a naming hint, we are free to name ours.

> **Confidence note:** copy, routes, colours, data attributes and class names are read directly from the site's HTML/CSS/JS. The *visual descriptions* of illustrated scenes (doors, flight, passport, house, basket…) are inferred from class names and CSS rules — **verify each against the screenshots / live site before building it.**

## Global shell (every page)
1. `a.skip` "Skip to content" → `#main`.
2. **Header** `#site-header` (scalloped/"cloud" bottom edge = `tp-header__hem`, white bar, active link shows a small paw under it) (`data-scrolled`, `data-hidden`, `data-home`): brand (logo.png 64px + "TeddyPups"), `nav[aria-label=Main]` (Home, Puppies, Happy families, How it works, FAQ, Visit & contact), WhatsApp button (≥md), **Menu** button → full-screen overlay "where to, friend?" with the same links + WhatsApp + phone (`+971 50 000 0000`), Close button. Menu items animate in (`tp-menu-in/out`, `tp-menu-link`).
3. **Mascot layer** `.pup-layer` (aria-hidden, global): a travelling Teddy that hops between "stops" on the home page. See ANIMATIONS.md §Mascot.
4. `main#main` page content.
5. **Footer** `tp-footer` (content: `docs/content/_footer.md`): brand blurb "Home, at last.", **Explore** list (Available puppies, Gone home, Happy families, How it works, Delivery & collection → `/how-it-works#delivery`, FAQ, Visit & contact), **Say hello** (WhatsApp, email, address "Downtown Dubai, United Arab Emirates", Instagram / TikTok / Facebook → instabizweb.com), logo + "© 2026 TeddyPups U.A.E. every puppy is family".
6. **Mobile bar** `[data-whatsapp-bar]` fixed bottom (≤md): "WhatsApp us" + "Call" (`tel:+971500000000`), `border-t-2 cocoa`, milk bg, safe-area padding.

- **Filter**: chips/links by breed and origin (`?breed=`, `?origin=`) — note the HTML served the full list for `?breed=maltipoo`, so filtering is client-side after hydration. Reproduce client-side; show empty state if none.
- **Grid of 15 sketch cards** (`tp-sketch`): blob-masked photo, "Available" badge, "▶ video" badge when the puppy has a video, name, `Breed · boy/girl · age`. Link → `/puppies/:slug`.

## `/puppies/:slug` — profile (42 pages: 15 available + 27 gone home; data in `data/puppies.json`)
Numbered hand-font chapter labels: **1 "hello, it's me"** → **2 "what comes with {name}"** → **3 "the way home"** → **4 "dear TeddyPups…"**.
1. **Gallery**: big photo + counter "‹ 1 / 4 ›" with prev/next and thumbnail list (2–4 photos each; AVIF for gone-home). Where a puppy has video (Max, K.T. Maltipoo, Maltipoo & Cavapoo, Maltipoo-female-2 …) show a `<video>` (`/media/*.mp4`, 3–6 MB — lazy, `preload="none"`, poster = first photo).
   Status pill: **Available** (green) or **Gone home ♥**. H1 = name (e.g. "Copper", or the breed if unnamed), sub = breed. Facts: **Breed · Boy or girl · Age · Where** ("Imported for you" or "In Dubai"). CTAs: **Ask about {name} on WhatsApp** (gone-home: *"Ask about a puppy like this"*) + **Send an enquiry** (`#enquire-{slug}`). Gone-home profiles use chapter 1 label **"the day they went home"**.
2. **Every Teddy Pup comes**: Vaccinated · Dewormed · Verified health certificate from licensed vets · Thoroughly checked before joining your family.
3. **The way home** — origin-dependent: *Imported for you* → "Coming home from abroad" 4 steps (Reserve your puppy / Personalized consultation / Import and arrival / Welcome home); *In Dubai* → the showroom flow (Explore / Choose / Meet before you choose / Pick-up or delivery — see how-it-works.md).
4. **Ask about {name}** form: Your name*, Phone or WhatsApp* ("With country code, e.g. +971 50 123 4567"), Email (optional), Your area (optional, "e.g. Dubai Marina"), Message (prefilled "Hi! I'd love to know more about {name} ({breed}).") + honeypot "Website" + **Send enquiry**.
5. **Previous pup / Next pup** cards (thumbnail + breed) — cyclic over the catalogue order.
- Page `<title>`: `{Name}, {Breed} puppy | TeddyPups U.A.E.` (unnamed: `{Breed} puppy ({sex}) | TeddyPups U.A.E.`) — see `title`/`description` in puppies.json.
